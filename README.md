## ✨ Features & Architecture

This portfolio is built on a modern frontend stack designed to deliver a highly interactive, responsive, and visually stunning user experience:

- **Next.js & React**: Utilizing React 19 and Next.js for high-performance rendering and layout management.
- **Three.js Particles**: Ambient, mouse-interactive 3D particle systems in the Hero background and footer.
- **Dynamic 3-Tier Orbital Skills System**: An interactive, rotating galaxy system displaying core technical skill badges that remain upright during rotation, featuring brand-specific saturation and frosted-glass tooltip descriptions.
- **GSAP (GreenSock Animation Platform)**: Smooth, scroll-linked timeline animations mapping progress curves, text reveals, and vertical timeline expansions.
- **Outro Video Auto-Autoplay with Gesture Warming**: Automatic unmuting of background audio as soon as the user enters the footer viewport, utilizing early page-wide gesture warming for bulletproof browser compatibility.
- **frosted Glass sidebar Experience & Certifications layouts**: Sophisticated blur backdrop overlays that blend typography with illustration backgrounds without sacrificing readability.

## 🚀 Getting Started

### Prerequisites

- Node.js (v18.x or higher)
- npm or yarn

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/varshu2024/portfolio-new.git
   cd portfolio-new
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Run the development server:
   ```bash
   npm run dev
   ```
   Open [http://localhost:3000](http://localhost:3000) in your browser.

### Building for Production

To create an optimized production build:
```bash
npm run build
```
The built files will be located in the `.next` and `out` directories.
